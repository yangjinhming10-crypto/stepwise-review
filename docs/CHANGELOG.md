### 附：独立评审验收方式（复验时参考）

- 评审方：至少两个互相独立的评审代理（本仓库开发时用了三个：宿主内置子代理、
  以及两个外部 headless 代理）。
- 验收标准五条：**A** 内部一致性（流程/效率原则/红线/场景自检互证无矛盾）；
  **B** 可执行性（中等能力代理只凭文档可无歧义执行）；**C** 关卡完整性（完整模式
  全关卡、轻量保底双关卡、例外严格限定）；**D** 关键失败模式无遗漏；**E** 安全性
  （各基线模式均无数据丢失路径）。
- 结论格式：**通过 / 不通过** + 逐条达标依据；发现分"阻断 / 建议"两级，建议级
  不阻断。有阻断项 → 修复后全部评审方重跑。
